Aplikasi ride-hailing berbasis web menggunakan PHP Native, MySQL, HTML, CSS, JavaScript, Leaflet.js, dan OpenStreetMap.

## Struktur Proyek

Folder disusun berdasarkan aset, konfigurasi, modul fitur, tampilan, API, database, dan file utama aplikasi.

## Menjalankan Proyek

1. Letakkan folder RUTEIN di direktori server lokal (misalnya `htdocs` pada XAMPP).
2. Buat database MySQL dan impor `database/rutein.sql`.
3. Sesuaikan konfigurasi koneksi pada `config/database.php`.
4. Buka `http://localhost/RUTEIN/` pada browser.

=======
Folder/File	Kegunaan : 
1. assetsMe = nyimpan CSS, JavaScript, dan gambar.
2. config = Menyimpan konfigurasi database.
3. modules = Menyimpan proses utama berdasarkan fitur aplikasi.
4. views = Menyimpan tampilan halaman website.
5. api = Mengelola pertukaran data antara frontend dan backend.
6. database = Menyimpan file SQL dan struktur database.
7. uploads = Menyimpan file yang diunggah pengguna.
8. index.php = Halaman utama atau pintu masuk aplikasi.
9. README.md = Berisi informasi dan panduan proyek.
