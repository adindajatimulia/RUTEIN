# RUTEIN
Folder/File	Kegunaan : 
1. assetsMe = nyimpan CSS, JavaScript, dan gambar.
2. config = Menyimpan konfigurasi database.
3. modules = Menyimpan proses utama berdasarkan fitur aplikasi.
4. views = Menyimpan tampilan halaman website.
5. api = Mengelola pertukaran data antara frontend dan backend.
6. database = Menyimpan file SQL dan struktur database.
7. uploads = Menyimpan file yang diunggah pengguna.
8. index.php = Halaman utama atau pintu masuk aplikasi.
9. README.md = Berisi informasi dan panduan proyek.
